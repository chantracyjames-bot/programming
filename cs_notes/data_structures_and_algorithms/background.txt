Data Structures and Algorithms
    - Programs are comprised of:
        - Data
        - Algorithms
            - where it is a complex struture
    - Problem Solving Process
        - Programming
            - is a problem solving process which could be viewed in terms of the following:
                - Problem Domain
                    - defines the problem and constraints of the solution
                    - the input or the raw data to process
                    - the ouput or the processed data
                - Machine Domain
                    - Storage Medium
                        - consists of serially arranged bits
                            - that are addresable as a unit
                    - Processing unit
                        - allows to perform arithmetic operations
                - Solution Domain
                    - links the Problem and Machine Domain
            - illustration:
                |-------------|           |--------------|           |-------------|
                |-------------|   /   \   |--------------|   /   \   |-------------|
                | | Problem | |  <----->  | | Solution | |  <----->  | | Machine | |
                |-------------|   \   /   |--------------|   \   /   |-------------|
                |-------------|           |--------------|           |-------------|
    - Algorithms
        - is a Finite set of instruction designed to accomplish a specific task
        - Characteristics of a good algorithm
            - Finiteness
                - the algorithm must have a clear starting point
                    - and must eventually end
                - an infinite loop is not an algorithm
            - Definiteness
                - each step must be clear and unambigous (concise)
                - example:
                    "Add some sugar"    - is not definite
                    "Add 2 tablespoons" - is definite
            - Input
                - the algorithm should accept zero or more inputs
                    - which are pieces of data to work with
            - Ouput
                - the algorithm must produce at least one result
                    - otherwise, what is the point of it?
            - Effectiveness
                - Each stepo must be simple enough to be done manually
                    - with just a pen and paper
