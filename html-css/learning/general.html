- syntax
        - doctype declaration
            - it indicates that the document is an HTML file
            - syntax:
                <!DOCTYPE html>
        - html element
            - every html file must have the html tag at the lowest level
            - syntax:
                <html>
                    <statements>
                </html>
        - elements
            - an element in html is defined by their tags
            - some elements require a starting tag and a closing tag
                - while some require no closing tags
            - closing tags
                - for elements that needs a closing tag
                    - the forward slash / is required to close the element
                - note that if a tag requires a closing tag
                    - if it is not present, contents may not show correctly
                - syntax:
                    <(tagname)>
                        <statements>
                    </(tagname)>
        - attributes
            - html elements can contain attributes
            - they provide additional indormation about the elements
                - they alway are specified at the start tag
                - usually in the form of name="value"
            - syntax:
                <(tag) (attribute)="(value)">
        - HTML is not case-sensitive
            - <p> is the same as <P>
            - it is generally recommmended to follow the lowercase format
                - due to being recommmended by the W3C
        - commemts
            - can be done inline and out of line
            - used to add extra descriptions or temporarily remove problematic lines

                <!-- (text) -->
