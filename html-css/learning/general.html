- HTML declaration
        - it indicates that the document is an HTML file
            - html means that the file is HTML 5
        - syntax:
            <!DOCTYPE html>

    - syntax
        - html element
            - every HTML file is declared by containing an html element at the lowest level
                - typically before declaring any other elements
            - syntax:
                <html>
                    <statements>
                </html>
        - elements
            - an element in html is defined by their tags
            - note some elements require a starting tag and a closing tag
                - while some require no closing tags, being an "empty" tag
            - closing tags
                - for elements that needs a closing tag
                    - the forward slash / is required to close the element
                - note that if a tag requires a closing tag
                    - if it is not present, contents may not show correctly
                - syntax:
                    <tagname>
                        <statements>
                    </tagname>
                - example:
                    <p>
                        idkman
                    </p>
            - empty tags
                - for elements that are only declared once
                    - without any closing tags
                - syntax:
                    <tagname>
                - example:
                    <br>
        - attributes
            - html elements are able to be declared with attributes
                - providing additional indormation about the elements
            - they always are specified at the start tag
                - usually in the form of name="value"
            - syntax:
                <tag attribute="value">
                    <statements>
                <tag>
        - HTML is not case-sensitive
            - <br> is the same as <BR>
            - it is by convention to follow the lowercase format
                - due to being recommmended by the W3C
            - example:
                <p>
                    Hello World
                </p>

            - used to add extra descriptions or temporarily remove problematic lines
