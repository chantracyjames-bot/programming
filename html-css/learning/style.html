- style attribute
        - used to add styles to an element
            - such as color, font, size, etc.
        - note that thsi is an attribute
            - the tag comes in the form of CSS
            - syntax:
                <(tag) style="(property):(value)">
            - example:
                <p style="color:blue">
                    blue
                </p>
        - list of properties
            properties          values          description                             example
            background-color    color           sets the bacground color                powderblue, tomato, green, etc.
            border              px type color   sets the border size, type and color    3px solid black, 2x solid DodgerBlue, etc.
            color               color           sets the text color                     blue, red, green, etc.
            font-size           px or %         sets the text size                      90px, 250%, etc.
            font-family         font            sets the font                           verdana, courier, etc.
            text-align          alignment       sets the text alignment                 right, center, left
