heading and paragraphs
    - in HTML
        - it is uncertain how the text in HTMLs are displayed
        - whether on large screens or small displays
            - by adding extra spaces and extra lines in the code
        - note that browsers automatically removed any extra spaces
            - and lines when the page is displayed
        - example:
                <p>
                    This paragraph
                    contains a lot of lines
                    in the source code,
                    but the browser
                    ignores it.
                    </p>

                    <p>
                    This paragraph
                    contains         a lot of spaces
                    in the source         code,
                    but the        browser
                    ignores it.
                </p>
    - <h#>
        - defines a heading
        - search engines typically use headings to index the structure and content of a web page
        - users usually skin though a page by its headings
            - it is recommended to use headings to show the document structure
            - it is also advised to use only 1 main heading which represents the main topic or title of a page
        - can range from 1 to 6 depending on the level of importance
            - 1 is the most important and 6 is the least important
            - 1 is typically used for the page title, 2 for the section titles, and 3 for the sub-sections
        - syntax:
            <h(number)>
                (text)
            </h(number)>
        - example:
            <h1>
                Heading where?
            </h1>
    - <p>
        - defines a paragraph
            - note that this element automatically starts at a new line
        - browsers automatically add somce whitespace
            - a margin before and after a paragraph
        - syntax:
            <p>
                (text)
            </p>
        - example:
            <p>
                "Hello World"
            </p>
    - <hr>
        - a horizontal line rule
            - a straight line from one side of the page to the other
        - a tag that defines a thematic break in an HTML page
            - most often displayed as a horizontal rule
        - used to separate content in an HTML page
            - or defines a change
        - note that this tag is an empty tag
            - meaning it has no end tags
        - syntax:
            <hr>
        - example:
            <p>
                Hello
                <hr>
                World
            </p>
    - <br>
        - a line break
            - similar to adding a newline to a print statement
        - used to start another paragraph
        - note that this tag is an empty tag
            - meaning it has no end tags
        - syntax:
            <br>
        - example:
            <p>
                Hello
                <br>
                World
            </p>
    - <pre>
        - defines proformatted text
        - the text inside this element is in a fixed width font
            - usually Courier
            - preserves both spaces and line spaces
        - syntax:
            <pre>
                (text)
            </pre>
        - example:
            <pre>
                Hello
                World
            </pre>

    - quotation and citations
        <blockquote>
            - defines a section of text that is quoted from another source
            - browsers usually indent this type of elements
            - syntax:
                <blockqoute cite="(url)">
                    (text)
                </blockqoute>
            - example:
                <blockqoute cite="https://github.com/chantracyjames-bot">
       blame tarcy

        <q>
            - used for short quotations
            - browsers usually insert quotation marks around the quotation
            - syntax:
                <q>
                    (text)
                </q>
            - example:
                <q>
                   "idkman"
                </q>
        <abbr>
            - defines an abbreviation or an acronym
            - typically used with the title attribute
            - syntax:
                <abbr title="(title)">
                    (text)
                </abbr>
            - example:
                <abbr title="i dont knowledge">
                    IDK
                </abbr>
        <address>
            - defines the contact information of the owner or document

                    lumbago

        <cite>
            - defines the title of a creative work

                </cite>
